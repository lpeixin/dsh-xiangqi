| File | What it is |

| `banner.png` | The README banner. Purpose-made artwork for this repository (dark "circuit grid" background, a xiangqi board fragment, the project name). Not a screenshot. |

  screenshots) to keep the repository — and the npm tarball, see NFR8 in `docs/DESIGN.md` — small.
- No personal information appears in either image: they show the plugin panel only.
